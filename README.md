# QAPTO

QAPTO is an early-stage marketplace app that connects users with available capacity and demand.

##  Features
- Create offers
- Matching system
- Chat between users
- Transaction flow (in progress)

##  Tech Stack
- Flutter
- Supabase

## 🎥 Demo
https://youtu.be/SSIns9zh8xU

##  Status
This is an early-stage prototype currently under development.

##  Vision
To simplify how people connect supply and demand in a fast and efficient way.
